Завантажити Core

Увійдіть або створіть обліковий запис, щоб завантажити.

Перший запуск

  1. Відкрийте завантажений файл та виберіть «Встановити».
  2. Запустіть Lokvetia Core з меню «Пуск». Відкриється браузер із локальною студією.
  3. У майстрі першого запуску підключіть власного AI-провайдера або налаштуйте локальну модель. Godot і моделі встановлюються окремо.

Це попередня версія: повний автоматичний цикл створення гри ще розробляється. Інсталятор не має цифрового підпису видавця; Windows може показати попередження. SHA-256 дозволяє перевірити цілісність файлу.

macOS і Linux: готові пакети ще не опубліковані.
