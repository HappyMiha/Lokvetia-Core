Що мені доступно?

Це лише пояснення: вибір не зберігається й не надсилається на сервер. Дату народження, документи, ім’я чи школу вводити не потрібно.

Збережіть задум у файл

Не додавайте паролі, адреси чи інші особисті дані. Текст залишається в цій вкладці до закриття. Кнопка завантажує файл на ваш пристрій; видаліть його, коли він більше не потрібен.

Коли потрібен дорослий

  1. Разом оберіть дозволений для країни та віку шлях. Дорослий перевіряє правила конкретного сервісу; чужий акаунт або ключ не обходить вікові обмеження.
  2. Оператор має перевірити повноваження дорослого, умови акаунта, згоду та захист даних. Галочка або вибір «18+» такою перевіркою не є. Наразі дитячий хмарний маршрут не схвалено.
  3. Перед будь-яким запуском дорослий погоджує окремий обмежений бюджет і перелік даних для передавання. Тут витрати, публікація та передавання ключів вимкнені.
  4. Передавання задуму в хмару означає обробку у провайдера за його правилами зберігання й видалення. Строки, навчання на даних і місце обробки перевіряються для конкретного договору. Збереження ключа ще не дозволяє запуск.

До завершення цих кроків користуйтеся задумом і шаблоном. Справжній локальний AI буде доступний лише після окремої перевірки моделей і пристрою.
